# 📱 Programação Mobile
As principais características da programação mobile envolvem a escolha entre o desenvolvimento nativo ou multiplataforma, a otimização rigorosa do hardware para poupar bateria e memória, o design focado na ergonomia do toque e na adaptação a múltiplas telas, a integração com recursos do dispositivo (GPS, câmera e biometria) e a dependência das diretrizes de publicação das lojas Google Play e App Store.
